05 — DEVELOPER EXPERIENCE

Docs, minus the fluff.

Three languages, one endpoint, no surprises. The ▶ Run it button below executes a real request and streams the raw response — watch the latency, not the landing page.

# one command. one dog. no ceremony.
curl https://dog.ceo/api/breeds/image/random

# response — a random dog, every time:
{
  "message": "https://images.dog.ceo/breeds/hound-afghan/n02088094_1003.jpg",
  "status": "200"
}
// the entire Pawstack client, in one statement
async function fetchDog() {
  const r = await fetch('https://dog.ceo/api/breeds/image/random');
  const j = await r.json();
  return j.message; // the face. you're welcome.
}

// cats are the same call, different endpoint
fetch('https://cat.ceo/api/breeds/image/random');
# python: stdlib only, no pip install
import requests

r = requests.get("https://dog.ceo/api/breeds/image/random")
face = r.json()["message"]
print(f"today's dog: {face}")
